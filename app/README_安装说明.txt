ScanPress 2.2
====================================
（自制扫描转 PDF 工具）

把 CZUR 等扫描仪拍的整本书图片，做成高清晰、小体积的 PDF。
三个标签页：图片转 PDF ／ PDF 工具 ／ 合并 PDF。

安装
----
把「ScanPress 2.2.app」拖到右边的「应用程序」文件夹即可。
首次打开若提示"来自身份不明的开发者"，在该应用图标上右键 → 打开 → 再点「打开」。


四种画质模式
-----------
黑白 · 最小        二值化 + JBIG2。文字书首选，1500 页的书约 32 MB。
                   建议同时勾上「提白 + 锐化」（几乎不占体积，底子更干净）。
                   ⚠ 几百页以上的大书请关掉「边缘精细化」，它会让体积翻倍。

彩色 · 文字锐化     推荐给彩色书、漫画、绘本。文字/线条按高分辨率黑白处理，
（MRC 混合分层）    色块用低分辨率彩色，两层叠加。
                   198 页漫画实测 14.2 MB，而普通彩色要 35.7 MB 且文字更糊。

灰度               保留灰阶，边缘平滑，体积约为黑白的 10 倍。
                   适合几十页、要放大细看的文稿。

原样彩色           不做分层，整页彩色 JPEG。


PDF 工具（对付已经有的 PDF）
------------------------
先点「体检」看看每本什么构成、能省多少（抽样实压估算），再勾选要处理的：

无损瘦身        黑白扫描件把老的 CCITT 编码换成 JBIG2，位图一个比特都不变，
                放大到任何倍数都和原件相同。实测四本自扫韩语书 354.8 MB → 148.6 MB。
                彩色页这条路帮不上忙。

加文字层        用 macOS 自带的 Vision 识别，加一层看不见的文字，让 PDF 能被
                Cmd+F 搜索。页面外观逐像素不变，每页只增加约 1 KB。
                支持韩/中/日/英/意等 30 种语言，完全离线。
                读者看到的永远是原图，所以偶有错字也看不见。

MRC 重制        把彩色页重做成「高分辨率文字层 + 低分辨率彩色底图」。
                ⚠ 这条会改变画质，先填「样张页」试几页再决定跑不跑全书。

原文件永远不会被改动，成品另存为新文件（后缀 _slim / _ocr / _mrc）。


使用流程
--------
1. 把扫描图文件夹（或若干张图片）拖进虚线框
2. 选色彩模式；没有封面的资料记得把「封面封底」设为「无封面」
3. 点「加入队列」（可以连着加好几本，每本用不同档位）
4. 点「开始」

设置会自动记住，下次打开还是你上次调好的样子。


运行环境
--------
不需要装任何东西。ImageMagick、jbig2enc、以及带 pikepdf 的 Python 运行时
都已经打包在应用里了，拖进「应用程序」即可使用。


其他
----
· 成品统一 A4，封面封底可保留原彩色
· 临时文件在 ~/.cache/scan2pdf，任务成功后自动清除；失败/中断时保留以便续做
· 合并 PDF 是无损搬运，不会重新压缩，画质与体积零损失
· 「图片转 PDF」的交付物是纯图片 PDF：不可搜索、不可选取文字、无目录书签
  （想要可搜索，转完再用「PDF 工具 → 加文字层」补上）
